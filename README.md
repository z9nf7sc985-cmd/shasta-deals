# Shasta Deals

Free local shopping deals and shopping lists for MeidasWell in Redding / Shasta County, CA.

Static site hosted with GitHub Pages. Prices are illustrative until replaced with manually curated open circular entries. No proprietary app scraping.

Live site: https://z9nf7sc985-cmd.github.io/shasta-deals/

## GitHub Pages
The `Deploy GitHub Pages` workflow deploys the repository on pushes to `main`. If Pages is not enabled automatically, open **Settings → Pages → Build and deployment → Source: GitHub Actions**.
